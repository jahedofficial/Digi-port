# Workspace Rules & Instructions

This project follows the Antigravity agent guidelines defined in [.agents/rules/guidelines.md](file:///c:/Projects/Digital%20Marketr/.agents/rules/guidelines.md):

1. **Stack**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Prisma ORM.
2. **Security**: All API keys, secrets, and credentials strictly in `.env.local`.
3. **API Standards**: Uniform JSON response formatting (`{ success: boolean, data?: ..., error?: string }`).
4. **UI/UX**: High-end modern marketing dashboard aesthetic with responsive dark themes.
5. **Language**: Bilingual support (Bengali / English) tailored to the user.
